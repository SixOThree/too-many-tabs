# Too Many Tabs

A 3 minute 44 second parody of a sitcom intro that keeps looping, about browser tabs that open faster than you can close them. Every frame and every sound is generated by the code in `tmt/`: cairo vector drawing, numpy/numba pixel effects, a numpy synthesiser, and Windows SAPI voices pitched onto the melody.

The song, lyrics, characters and jokes are all original.

The QR code on the purple crash screen links back to this repository. The address is `REPO_URL` in `tmt/config.py`.

## Rebuild

```powershell
.\.venv\Scripts\python.exe render.py audio --stems out\audio\stems   # soundtrack + per-bus stems (~90 s)
.\.venv\Scripts\python.exe render.py video --res 1080 --workers 10   # frames -> build\video_1080.mp4 (~7 min)
.\.venv\Scripts\python.exe render.py mux --res 1080                  # -> out\too_many_tabs_1080p.mp4
.\.venv\Scripts\python.exe render.py video --res 4k --workers 10     # 3840x2160, same drawing code
.\.venv\Scripts\python.exe render.py mux --res 4k                    # -> out\too_many_tabs_4k.mp4
.\.venv\Scripts\python.exe render.py still 12.5 150                  # preview frames -> build\stills
```

A partial range renders with `--from` and `--to` (seconds).

## Layout

| Path | What it is |
|---|---|
| `tmt/score.py` | Section timeline, chords, melody, lyrics, spoken lines |
| `tmt/music.py` | Arrangement, mixing, the YTP and recursion audio edits, mastering |
| `tmt/synth.py` | Drums, instruments, sound effects, reverb |
| `tmt/voice.py` | Robot singer: TTS words time-warped onto notes (TD-PSOLA plus vocoder) |
| `tmt/edits.py` | Stutter/reverse/speed edits shared by picture and sound |
| `tmt/cast.py`, `tmt/gfx.py` | Characters, browser UI, icons, text |
| `tmt/common.py`, `tmt/loop.py`, `tmt/scenes.py` | The scenes |
| `tmt/post.py`, `tmt/video.py` | VHS/glitch pixel effects, parallel render, mux |

## Output folder (`out/`)

| Path | What it is |
|---|---|
| `too_many_tabs_1080p.mp4` | Master: 1920x1080, 30 fps, x264 CRF 15, AAC 320k (1.1 GB) |
| `too_many_tabs_1080p_share.mp4` | Same video at CRF 22 (490 MB) |
| `audio/soundtrack_master.wav` | Final 48 kHz stereo mix |
| `audio/stems/*.wav` | Per-bus float stems at master gain, before the limiter |
| `audio/vocal_tests/` | Early singer experiments and their spectrograms |
| `audio/tts_cache/` | Every raw SAPI voice clip used |
| `stills/` | One PNG every 2 seconds |
| `sheets/` | Contact sheets, cast and UI sheets, font test, soundtrack spectrogram |
| `logs/` | Render log |
